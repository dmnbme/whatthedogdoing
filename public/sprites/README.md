# Yamper Sprites

放这 5 张图（PNG，透明背景，建议 200x200px）：

- idle.png   → Yamper 站立待机，尾巴可以微动
- type1.png  → 打字帧 A（爪子抬起）
- type2.png  → 打字帧 B（爪子落下）
- burst.png  → 高速打字（加特效，比如电弧）
- sleep.png  → 趴着睡觉（30s 没打字后出现）

推荐素材来源：
- https://www.spriters-resource.com/ 搜索 "Yamper"
- Pokemon Showdown 的精灵图（gen8）
- 自己用 Aseprite 画像素风也很棒

文件名必须和上面一致，否则需要改 App.vue 里的 SPRITES 对象。
